# Reusable backend build prompt

Create a production-ready Node.js backend for a React portfolio admin panel. Use Node 20+, Express 5, MongoDB/Mongoose, Zod validation, JWT admin authentication, bcrypt password hashing, Helmet, strict CORS, rate limiting, Multer uploads, and Nodemailer for replies. Build public endpoints for published projects/blogs/site settings and contact submission. Build authenticated admin CRUD for projects and blogs, an inbox with new/read/replied/archived states and email replies, dashboard counts, media uploads, and site settings. Support draft/published content, slugs, featured blogs, project sort order, and image URLs. Return consistent JSON `{ item }`, `{ items }`, or `{ message }`, never expose password hashes, validate image MIME/size, centralize errors, include `.env.example`, admin seed script, README, and tests. API routes must match the contract documented in this repository's `backend/README.md`. Keep upload storage abstractable so local disk can be replaced by S3 or Cloudinary. Do not trust the frontend route guard; enforce admin authorization on every `/api/admin/*` route.
